# 5주차 데이터 기반 전략: 코스피200 투자자 흐름 → 미니코스피200 장중 매매

제출일: 2026/11/20(금) 23:59

NFT 팀 5주차 보고서입니다. 숫자는 `foreign_flow/results/` 원본 파일에서 가져왔습니다. 금요일(11/20) 결과는 장이 끝난 뒤 채웠습니다.

이번 주 질문은 하나였습니다. "외국인이 코스피200 선물을 사고파는 흐름을 보면 몇 분 뒤 가격을 맞힐 수 있나." 외국인이 정보를 더 가진 쪽이라는 연구는 많은데, 거의 다 일별입니다. 장중 몇 분 단위로도 그런지 직접 데이터를 쌓아서 보기로 했습니다.

- NH API 투자자 동향은 **분별 과거를 주지 않습니다.** 그래서 화요일부터 서버에서 30초마다 직접 쌓았습니다. 웹소켓 체결·호가도 같이 받았습니다 (2절).
- 화요일 하루로 규칙을 정하고, 수\~금은 그 규칙으로 미니코스피200 모의계좌에 주문했습니다. 규칙을 정한 뒤에는 정해 둔 것(밤마다 sd·θ 갱신) 말고는 바꾸지 않았습니다.
- 수·목은 손실이었습니다. 원인을 쪼개 보니 흐름이 가격을 **1분 늦게 따라가고**, 화요일은 외국인이 한 방향으로 계속 팔던 특이한 날이었습니다 (7절). 이걸 바탕으로 목요일 밤에 세 번째 규칙(국면 필터)을 고정해서 금요일에 시험했습니다 (8절).
- **결과: 세 규칙 모두 미리 정한 기준으로 기각입니다.** 규칙 1은 표본 밖 94건 −7.24bp(t −2.39), 규칙 2는 138건 −3.71bp(t −1.47), 규칙 3은 금요일 31건 −0.34bp 였습니다 (수수료는 NH 미니코스피200 HTS·API 요율 0.00145%). 모의계좌는 수·목·금 합계 **−1,587,790원**(금요일만 +36,939원)입니다.
- 장이 끝난 뒤 18\~20일로 손절 1pt·하루 손실 한도 20만 원을 정해 실행기에 넣었습니다. 이번 주 실행에는 없었고 다음 실행부터 적용됩니다 (6-4절).
- 국내 모의 서버(`apidemo`)와 국내 모의 키만 썼고, 실전 계좌로는 주문하지 않았습니다.
- 규칙을 정한 과정과 진단은 [전략 근거](foreign_flow/week05-외국인흐름-전략-근거.md)와 [화요일 진단](foreign_flow/results/analysis_why_tuesday.md)에 자세히 적었습니다.

## 2. 실행 방법

### 2-1. 준비

Python 3.10, `requests`, `websockets`, `numpy`, `pandas`, `pytest`. API 키는 저장소 밖(국내 모의 키)에 두고 토큰은 파일로 저장해 다시 씁니다. 이 맥은 scipy 바이너리가 안 올라와서 statsmodels 대신 Newey-West 를 직접 구현했습니다.

```bash
cd week05/foreign_flow
uv venv .venv --python 3.10 && uv pip install --python .venv -r requirements.txt
.venv/bin/python -m pytest -q tests          # 23개
```

### 2-2. 서버 (cron)

```bash
*/5 * * * *        cd <경로>/week05/foreign_flow && ./run.sh        # 수집기, 평일 08:50~15:50 에만 돎
*/5 8-15 * * 1-5   cd <경로>/week05/foreign_flow && ./run_live.sh   # 실행기, 08:55~15:35
```

둘 다 이미 돌고 있으면 바로 끝나서 5분마다 불러도 겹치지 않습니다. 실행기는 투자자 동향을 직접 부르지 않고 수집기가 쓰는 `rest.jsonl` 을 매 분 t+3초에 읽습니다. API 호출도 웹소켓 접속도 늘지 않습니다.

### 2-3. 장 끝난 뒤 (맥)

```bash
FF_SERVER=root@<서버> ./nightly.sh 20261119 20261120   # 원본·실행 기록 가져와 1분 표, 다음 날 규칙 2 갱신, 푸시
# 서버는 다음 날 08:55 전에 git pull
.venv/bin/python analyze.py --train 20261117                               # 규칙 1 고르기 (화요일)
.venv/bin/python analyze.py --regime-freeze 20261117,20261118,20261119 --for 20261120   # 규칙 3 고정 (목요일 밤, 한 번만)
```

### 2-4. 금요일 판정

```bash
.venv/bin/python analyze.py --train 20261117 --test 20261118,20261119,20261120   # 규칙 1
.venv/bin/python analyze.py --combo-test 20261118,20261119,20261120              # 규칙 2
.venv/bin/python analyze.py --regime-test 20261120                               # 규칙 3
```

미니 계좌가 하나라 같은 종목에 두 규칙이 동시에 주문을 내면 포지션이 엉킵니다. 그래서 하루에 한 규칙만 주문하고 나머지는 데이터 위에서 다시 계산합니다.

### 3-3. 미리 알고 있던 약점

- 학습이 화요일 하루였습니다. 그것도 오전이 지연으로 빠진 하루입니다.
- 규칙 2는 화요일 결과를 보고 추가했고, 규칙 3은 수·목 결과를 보고 만들었습니다. 둘 다 사후에 고른 가설이라 판정을 미리 적어 두고 하루씩만 시험합니다.
- θ 0.5 는 하루 40\~60건 거래한다는 뜻이라, 거래당 우위가 작으면 비용에 바로 먹힙니다.

## 7. 왜 화요일만 맞았나 (`results/analysis_why_tuesday.md`)

### 7-1. 흐름은 가격을 1분 늦게 따라간다

이번 분 흐름과 1분 수익의 상관 (세 날 범위):

| | 외국인 | 개인 |
| --- | --- | --- |
| 1분 전 수익과 | +0.49 \~ +0.58 | −0.20 \~ −0.38 |
| 1분 뒤 수익과 | −0.08 \~ +0.02 | −0.03 \~ +0.07 |

가격이 먼저 움직이고, 1분 뒤 흐름에 외국인 순매수로 찍힙니다. 스냅샷 시각도 행 시각보다 중앙값 60초 늦었습니다. 외국인이 시장가로 가격을 밀고 개인이 지정가로 받는 그림과 맞습니다. 그러니 "5분 흐름"은 대부분 "직전 5분 가격 변화"의 다른 표현이고, 다음 5분 정보는 흐름이 앞으로도 이어질 때만 남습니다.

### 7-2. 화요일 학습엔 오전이 없었다

화요일은 09\~11시 코스피200 선물 투자자 동향이 최대 52분 늦어 그 시간을 통째로 버렸습니다. 수·목 오전은 부호가 반대였습니다(조합 b 수 −6.97, 목 −12.0). 화요일에 쓸 수 있던 시각만 남기면 수 +0.57, 목 +1.26 으로 0 근처입니다.

### 7-3. 흐름이 이어졌나, 밀린 가격이 남았나

겹치지 않는 5분으로 나눠 봤습니다.

| | 같은 5분 가격을 미는 힘 λ | 다음 5분에도 흐름이 이어짐 ρ | 다음 흐름을 통제한 현재 흐름 |
| --- | --- | --- | --- |
| 화 | +9.5 (t 3.3) | **+0.53** | +0.2 — 되돌림 없음 |
| 수 | +17.5 (t 5.3) | +0.12 | −5.6 (t −1.7) — 되돌림 |
| 목 | +13.4 (t 3.8) | +0.32 | −8.1 (t −2.3) — 되돌림 |

미는 힘은 오히려 수·목이 더 컸습니다. 다른 건 화요일엔 외국인이 계속 같은 방향으로 밀었고, 밀린 가격이 돌아오지 않았다는 점입니다. 날별 b 세 개가 같다는 가설은 Q ≈ 16, p < 0.001 로 기각됩니다. 화요일 11시 뒤 효과는 30분 블록 부트스트랩 95% [+3.83, +9.56] 로 몇 분짜리 우연도 아니었습니다.

그날 시장도 이 그림과 맞습니다. 화요일은 외국인이 현물을 1.4조 넘게 팔아 코스피가 9개월 만에 5,000 아래로 내려간 날(−2.59%)이고, 수요일은 엔비디아 실적으로 높게 시작했다가 4,943 까지 밀린 뒤 반등한 V자 날, 목요일은 수능일 늦은 개장에 장 초반 밀렸다가 오후 반등한 날이었습니다.

## 8. 세 번째 규칙: 흐름이 이어질 때만 (금요일 시험)

7절에서 "외국인 흐름이 이어질 때만 신호에 정보가 남는다"가 나와서, 그걸 규칙으로 만들었습니다.

- 직전 60분 안에서 외국인 5분 흐름과 그 5분 전 5분 흐름의 상관 ρ 가 0보다 클 때만 규칙 2 신호로 진입합니다. 값이 50개 안 되면 진입하지 않아서 10시 전후까지는 거래가 거의 없습니다.
- 후보 30여 개(창 60/90, ρ 하한 0/0.2/0.4, θ 다섯 개)를 17\~19일에서 돌려 1등을 골랐습니다(`diag/regime_search.py`).
- 학습 80건 +4.19bp, 사흘 다 플러스(+8.7, +1.8, +2.5). 필터 없이 같은 θ 면 157건 +0.53bp.
- 약한 점: t 1.55, 날 안에서 ρ 를 원형으로 밀어 만든 가짜 필터 500개 중 10% 가 이 이상(`diag/regime_check.py`). ρ 하한 0.4 는 오히려 나빴는데, 기제대로면 좋아져야 합니다.
- 실행기를 사흘로 재생해 분석과 진입 시각 일치(25·28·27건), 필터가 t 이후 값을 안 쓰는지 테스트로 확인했습니다.

**판정 (미리 적어 둠):** 금요일 비용 후 평균 > 0, 그리고 필터 없는 같은 규칙보다 큼. 둘 다면 "국면 가설과 맞는 하루", 하나라도 아니면 기각. 둘 다 맞아도 하루라 "더 쌓아 볼 가치가 있다"까지만 씁니다.

| 금 11/20 | 거래 | 비용 전 | 비용 후 | t | 승률 |
| --- | --- | --- | --- | --- | --- |
| 규칙 3 (필터) | 31 | +1.07bp | −0.34bp | −0.07 | 55% |
| 필터 없는 같은 규칙 | 65 | −0.43bp | −1.65bp | −0.48 | 55% |
| 모의계좌 (예수금) | 31 | 청산손익 +71,000원 | 수수료 뒤 +36,939원 | | |

**기각입니다.** 필터 없는 것보다는 나았지만(조건 2), 비용 후 평균이 −0.34bp 로 0 아래라 조건 1이 틀렸습니다.

모의계좌는 플러스인데 판정은 마이너스인 건 스프레드 계산 차이입니다. 판정은 진입 때 스프레드를 왕복으로 통째로 물리는데, 금요일 실제 시장가 체결은 그보다 나았습니다. 같은 31건을 중간가로 체결하면 수수료 전 +124,500원, 반 스프레드씩 물리면 −6,000원인데, 실제 청산손익 +71,000원은 그 사이입니다. 하루 31건, 거래당 +0.3bp 수준이라 체결이 조금만 나빠도 뒤집힙니다.

금요일엔 투자자 스냅샷 지연이 하루 종일 0% 였고 미니 호가도 빠진 분이 없어서, 나흘 중 데이터가 가장 깨끗한 날이었습니다. 깨끗한 날에도 안 맞았다는 게 7절 결론(1분 지연, 흐름이 가격을 따라감)과 맞습니다. 진입은 10:00\~11:13, 12:46\~13:58, 14:52\~15:20 세 덩어리였고, 그 사이엔 ρ 가 0 아래라 쉬었습니다.

## 10. 알게 된 것과 한계

### 10-1. 알게 된 것

- 공개 REST 투자자 동향은 실제로 1분 늦게 들어오고, 흐름 자체가 가격을 따라가는 쪽이라 장중 5분 예측에 정보가 거의 안 남습니다. 연구에서 말하는 "외국인 정보 우위"는 일별로는 맞을지 몰라도, 이 데이터 경로로 몇 분 단위에서 쓰기는 어렵습니다.
- 하루로 학습하면 그날 국면을 배웁니다. 화요일은 오전이 빠진 일방적 매도일이었고, 그런 날에만 통하는 신호를 골랐습니다. 날 사이 이질성 검정(Q)을 학습 때 했으면 더 일찍 알았을 겁니다.
- 실행기와 분석이 같은 신호 코드를 쓰게 한 덕에, 손실이 났을 때 "실행이 틀렸나 신호가 틀렸나"를 바로 가를 수 있었습니다.
- 위험 관리(하루 한도)는 손실을 줄이지만 마이너스 신호를 플러스로 바꾸지는 못했습니다.
- 세 규칙을 모두 미리 적은 기준으로 판정했고 셋 다 기각했습니다. 규칙을 하나씩 더할 때마다 "결과를 보고 만든 가설"이라고 적어 두고 다음 날 하루로만 시험한 덕에, 마지막 날 모의계좌가 플러스였어도 그걸 성공으로 착각하지 않을 수 있었습니다.

### 10-2. 한계

- 데이터가 나흘입니다. 7절 국면 이야기와 규칙 3은 앞 사흘을 보고 만든 가설이고, 금요일 하루로 기각됐지만 하루로 기각한 것도 약한 근거입니다.
- 손절·하루 한도는 사흘을 보고 정한 값이고, 아직 한 번도 실제로 돌지 않았습니다.
- 규칙 2·3은 결과를 보고 추가했습니다. 하루씩 미리 적은 기준으로 시험했지만, 여러 번 고친 만큼 하나라도 맞을 확률은 올라갑니다.
- 수집기가 장 시간을 고정(08:50\~15:50)으로 잡아서 수능일 같은 시간 변경을 따라가지 못했습니다.
- 웹소켓 체결 방향·호가 불균형은 모아 놓고 이번 주 규칙에는 쓰지 않았습니다.

## 11. 향후 계획

1. 웹소켓 체결 방향(`aggr`)·호가 불균형으로 같은 질문을 다시. 이건 지연이 없습니다.
2. 규칙 3을 다음 주에도 종이로 돌려 날을 더 쌓기. 국면 필터가 진짜인지는 열흘은 있어야 말할 수 있습니다. 손절·하루 한도가 실제로 도는지도 같이 봅니다.
3. 투자자 흐름은 일 단위(외국인 선물 순매수 → 다음 날)로 다시 보기. 1분 지연이 상관없는 지평입니다.
4. 수집기·실행기가 거래소 운영 시간 변경을 따라가게 하기.

API 키, 토큰, 계좌번호 등 개인정보는 이 폴더에 넣지 않았습니다. 실행 기록의 계좌 값은 실행기가 지운 채로 남아 있습니다.
