## 2. 실행 방법

### 2-1. 준비

Python 3.12, `requests`, `numpy`, `pandas`, `statsmodels`. API 키는 저장소 밖 `~/.nh_futures/credentials_overseas.env`(해외 모의 키)에 두고, 토큰은 `~/.nh_futures/token_overseas_demo.json`에 저장해 다시 씁니다.

### 2-2. 쌍 찾기와 백테스트

```bash
cd week04
python3 list_products.py                 # 해외 품목 전체
python3 fetch_bars.py                    # 52개 근월물 1분봉 (21일)

python3 fetch_long.py                    # 연결선물 5분봉 2026-05-01~
python3 cointegrate_long.py              # 6개월 공적분
python3 backtest_rv.py                   # 15~18시 롤링 β 11쌍
python3 test_rv_stats.py                 # 평균회귀 검정 (가짜 페어 대조)
python3 backtest_rv_full.py --news       # 하루 전체, 채택 (포지션 손절 + 발표 금지, 288개 조합)
python3 stats_rv_full.py                 # 채택값 통계

```

### 2-3. 실행

```bash
python3 rv_runner.py                     # 직접 만든 실행기, 종이 체결
python3 rv_runner.py --orders            # 모의 주문 (11/12 23:50 정리 후 종료, 11/13엔 안 켜짐)
```

이번 모의 주문은 서버의 팀 앱으로 냈습니다. 앱 「전략주문 › 스프레드」 탭에 `spread_gc_si_rv.py`를 올리고 다리 네 개(gc·si는 신호용, mgc·msi는 주문용)를 정한 뒤 「모의 주문」으로 시작합니다. 앱이 실행마다 `run.json`·`journal.jsonl`·`summary.json`·`api_log.jsonl`을 남기고, 그걸 내려받아 `results/runs/`에 두었습니다.

## 3. 전략과 매매 계획

### 3-1. 대상 상품

| 구분 | 금 | 은 |
| --- | --- | --- |
| 신호 | `GCZ26` (100온스, 틱 0.1 = $10) | `SIZ26` (5,000온스, 틱 0.005 = $25) |
| 주문 | `MGCZ26` (10온스, 틱 0.1 = $1) | `MSIZ26` (1,000온스, 틱 0.005 = $5) |
| 거래 시간 (KST) | CME 08:00\~다음 날 07:00, 매일 07:00\~08:00 휴장 | 같음 |
| 수수료 | 마이크로 편도 계약당 $2 | 같음 |

신호는 거래가 많은 일반 계약 시세로 내고(백테스트와 같은 시세), 주문은 마이크로로 냅니다. 마이크로는 가격이 일반 계약과 같아서 신호를 그대로 옮겨 쓸 수 있고, 금 3계약(약 $12만)에 은을 β만큼 붙여 달러 중립을 맞추기 쉬운 크기입니다.

### 3-2. 쌍을 고른 과정

자세한 건 [전략 근거 3\~6절](week04-전략-근거.md)에 있습니다.

1. **스크리닝** (15\~18시, 52개 → 15개): 30분 움직임이 왕복 비용의 몇 배인지로 줄 세움. 지수·닛케이·금속·에너지는 충분하고, 환율·금리는 빠짐.
2. **공적분** (3주 105쌍, 6개월 91쌍): 꾸준한 건 NKD↔NIY(29개 창 중 16개 통과)뿐. 금↔은 p 0.33, 반감기 175시간.
3. **롤링 β** (11쌍 × 60조합, 15\~18시): 금·은만 학습 55%·검증 43%가 플러스. 비용 0이면 92%·90%라 되돌림은 있는데 비용(약 3bp)이 거래당 총수익(약 4bp)과 비슷함.
4. **우연이 아닌지**: 금의 어느 날과 은의 다른 날을 짝지은 가짜 페어와 비교. \|z\|>2에서 60분 안에 돌아오는 비율 53% vs 28\~36%, 30분 뒤 z 회귀 기울기 −0.08(t −2.6) vs +0.05.
5. **하루 전체로 다시 정하기** (288개 조합): 실제로 돌릴 땐 CME 23시간을 다 쓰기로 하고 값을 처음부터 다시 정함. 학습 이웃 평균 상위권 중 거래가 하루 0.6건 나오는 조합을 채택.

### 3-3. 매매 규칙

| 구분 | 값 |
| --- | --- |
| 스프레드 | log GC − β·log SI. β·평균·σ는 직전 **72개** 5분봉(6시간)으로 매 봉 다시 추정 |
| 진입 | z > **3.5** → 스프레드 매도 (금 매도·은 매수), z < −3.5 → 스프레드 매수 |
| 청산 | z가 **0**을 지나면 |
| 손절 | 진입 때 β·σ로 고정한 스프레드가 진입보다 **1.5σ** 불리해지면 |
| 지표 발표 | 뉴욕 08:15\~09:00 (지금 KST 22:15\~23:00) 진입 금지, 들고 있으면 청산 |
| 휴장 | CME 일일 휴장(뉴욕 17:00) 5분 전 정리. 창(6시간)이 휴장을 건너면 신호를 버림 → 실제로 신호가 나오는 건 KST 14시쯤부터 다음 날 06:50 |
| 수량 | 금 MGC 3계약, 은 MSI = round(\|β\| × 금 명목 ÷ 은 1계약 명목). β가 매 봉 바뀌어서 은 계약 수도 진입마다 달라짐: 백테스트 진입 β 중앙값 0.4면 1계약, 11/11 실제 진입 때는 β 0.65라 2계약 |
| 일일 한도 | 그날 손절 3번이면 진입 중단 |

### 3-4. 미리 알고 있던 약점

- 비용을 뺀 수익은 통계적으로 유의하지 않습니다 (부트스트랩 1만 번, P 0.055). 거래당 우위(4.6bp)가 비용의 두세 배 정도라 몇 건에 결과가 흔들립니다.
- 하루 0.6건이라 사흘 실행으로는 거래가 한두 건 나오는 게 정상입니다. 실행 기록은 수익보다 실행기 동작 확인용입니다.
- 손절선이 한 종목 가격이 아니라 스프레드라서 거래소 STOP 주문으로 걸 수 없습니다. 실행기가 죽으면 손절도 같이 멈춥니다.

NH선물 해외 모의거래는 매 영업일 KST 07:00:00\~23:59:59에만 됩니다 ([NH선물 OPEN API 모의거래 안내 기사](https://m-economynews.com/news/article.html?no=59586)). 실제 CME 금·은은 08:00\~다음 날 07:00에 거래되니, 자정부터 07시까지는 거래소는 열려 있어도 모의계좌는 닫혀 있습니다. 이 시간에 낸 주문은 거부되지 않고 접수(주문번호 있음)만 된 채 체결되지 않습니다. 11/12 00:35 주문이 이 경우였습니다.

2·3주차는 서울 낮(08:45\~15:45)에만 거래해서 이 제약에 걸릴 일이 없었고, 이번에 처음 23시간 도는 전략을 올리면서 놓쳤습니다. 백테스트도 23시간 기준이었습니다.

11/11 00:00:08\~00:05:05에 낸 주문 네 건은 자정이 지났는데도 체결됐습니다(체결시각·잔고·수수료 모두 기록에 있음). 자정 직후 몇 분은 마감 처리가 늦게 걸리는 것으로 보고, 00:35부터는 체결되지 않는다는 것만 기록으로 확인했습니다.

## 9. 시도에서 알게 된 것과 한계

### 9-1. 알게 된 것

- 교과서 쌍이 공적분으로 안 묶였습니다. 하루 전체 37개 품목으로 넓혀도 꾸준한 건 같은 지수(닛케이)뿐이었습니다. 그래도 금·은은 β를 계속 다시 잡으면 몇 시간 안에서는 가짜 페어보다 확실히 많이 되돌아왔습니다. "묶여 있다"와 "되돌아온다"는 다른 얘기였습니다.
- 실행 환경부터 확인하고 그 안에서 백테스트를 했어야 했습니다. 23시간으로 값을 고른 뒤 모의계좌 시간으로 자르니, 수익이 난 시간이 빠졌습니다. 합계만 보지 말고 어디서 벌었는지 쪼개 봤으면 더 일찍 알았을 겁니다.
- 두 다리 실행기에서 가장 쓸모 있었던 건 "결과를 모르면 멈추기"였습니다. 11/12 00:35에 금 주문이 접수만 되고 체결이 안 됐을 때, 은 주문을 이어서 냈다면 은 한쪽만 들고 있었을 겁니다.
- 시세 한 봉이 틀리면 롤링 창 전체가 6시간 동안 틀립니다. 신호용(일반 계약)과 주문용(마이크로) 가격을 같이 받고 있으니, 둘이 크게 어긋나는 봉은 버리는 확인을 넣을 수 있습니다.

### 9-2. 손익

- 모의계좌(11/10\~11/12): 거래 1건 **−$80** (손익 −$60, 수수료 $20). 그 1건은 가짜 신호였고, 진짜 신호 1건은 모의계좌 체결 시간 밖이라 체결되지 않았습니다.
- 백테스트(23시간): 학습 +$2,915, 검증 +$463. 모의계좌가 열린 07\~24시만으로는 검증 −$53 (발표 자료 수치).
- 세 주 동안 같은 질문을 했습니다. 되돌림은 있는데, 비용을 넘느냐. 2주차 국내 달러선물은 넘었고, 3주차 MKU는 못 넘었고, 4주차 금·은은 23시간으로는 간신히 넘었지만 실제로 거래할 수 있는 시간만으로는 못 넘었습니다.

### 9-3. 한계

- 비용 뺀 수익은 유의하지 않습니다 (P 0.055). 검증은 10건이고, 학습 최고 거래 한 건(+$1,266)을 빼면 학습 합계가 +$1,649로 줄어듭니다.
- 발표 금지는 뉴욕 08:30 발표만 넣었습니다. 10:00 발표(ISM 등)나 FOMC는 안 넣었습니다.
- 모의계좌 실행은 실제로 돈 시간이 이틀이 안 되고, 거래는 1건입니다. 체결가·슬리피지를 백테스트와 비교할 만큼 기록이 쌓이지 않았습니다.
- 모의계좌 거래 시간(07:00\~23:59:59)의 출처는 NH선물 모의거래 안내 기사입니다. 자정 직후 몇 분 동안 체결된 이유는 확인하지 못했습니다.
- 시간대 해석(밤에 벌고 뉴스 시간에 잃는다)은 밤 거래가 검증 3건뿐이라 가설입니다.
