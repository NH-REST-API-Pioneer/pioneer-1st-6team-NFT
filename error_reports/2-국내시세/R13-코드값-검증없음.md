# R13 · 국내 시세 요청의 코드값 필드가 범위 밖 값을 오류 없이 받아 다른 값으로 처리합니다

- 섹터: 2 · 종류: 입력 검증 누락 (명세와 다른 동작) · 검증: 실제 호출 · AI 영향: 상 (오타 하나로 다른 데이터가 조용히 옴)
- 상태: 올릴 준비 됨

```text
[제보] 국내 시세 API 의 코드값 필드(nght_tp·exch_cd·inq_tp·dcnt 등)에 명세에 없는 값을 넣으면 오류 없이 다른 값으로 처리됩니다

팀: team-06
환경: 모의 (apidemo.futures.co.kr), 2026-11-22 22:53 최초, 22:54·22:55 재현
대상: 국내_차트(일)·차트(분)·호가·투자자직전매매동향 (개발자센터 API 가이드 > 국내주간 시세)

재현 절차:
  1. 접근토큰 발급
  2. 아래 필드만 명세에 없는 값으로 바꿔 호출하고, 정상 값으로 보낸 결과와 비교
기대 결과:
  설명에 적힌 값(예: nght_tp 「1:주간, 2:야간」) 밖의 값은 다른 필드처럼 ETR018(형식 불일치)·ETR019(숫자 아님)로 거절

실제 결과 (모두 HTTP 200):
  | API / 필드 (명세 값)                      | 넣은 값        | 실제 처리                              |
  | 차트(일·분) nght_tp (1 주간, 2 야간)       | 9, A           | 야간(2)과 같은 데이터                   |
  | 호가 exch_cd (KSP 주간, NDV 야간)          | XXX, 123       | 주간(KSP)과 같은 데이터                 |
  | 투자자동향 inq_tp (1 수량, 2 금액)          | 9              | 금액(2)과 같은 데이터                   |
  | 차트(일) cidx_yn (0 안함, 1 연결)           | 9              | 0 과 같음                              |
  | 차트(일) fut_cidx_exp_mod (0, 1)           | 9              | 0 과 같음                              |
  | 차트(분) dcnt (묶음 개수, 1분봉이면 1)      | 0, abc         | 30초 간격 봉 (153430, 153400, 153330 …) |
  → 같은 범위 밖 값인데 어떤 필드는 「야간」, 어떤 필드는 「주간」, 어떤 필드는 「0」으로 처리돼 규칙이 없음
  → 숫자 필드도 처리가 다름: 차트(일) req_qty="abc" 는 HTTP 400 ETR019 「값은 숫자 형식이어야합니다」로 거절, 차트(분) dcnt="abc" 는 30초 봉으로 받아들임
  → dcnt 0·문자로 받는 30초 봉은 명세에 없는 동작
  → ETR019 는 오류 코드 페이지·정의서에 없는 코드

참고: 범위 밖 prd(선물전체시세 99)·opt_prd(999)는 EMG_001 로 거절되지만 메시지가 「'99' MarketCode error [SDIF7023Q01@dom]」,
      「'999' get_section error [SDIF7172Q01@dom]」처럼 내부 TR 코드가 그대로 보이고 정의서 메시지(「[%s] 거래소를 찾을 수 없습니다」)와 다릅니다.

로그·캡처: (저장소) error_reports/2-국내시세/logs/market_values_20261122_225432.json, logs/market_repro_20261122_225559.json, logs/market_20261122_225342.json
          재현 스크립트 error_reports/2-국내시세/check_market.py, check_market_values.py
영향:
  - nght_tp·exch_cd 오타 하나로 주간 대신 야간(또는 그 반대) 데이터를 받아도 알 수 없음 → 전략 계산이 조용히 틀어짐
  - 프로그램·AI 에이전트가 만든 요청 값이 틀려도 서버가 받아 주니 검증 단계에서 잡히지 않음
개선 제안:
  1) 설명에 값이 정해진 필드는 그 밖의 값을 ETR018 로 거절
  2) dcnt 의 허용 범위와 0(30초 봉) 같은 특수값이 있다면 명세에 적기
  3) ETR019 를 오류 코드 페이지·정의서에 추가하고, EMG_001 메시지를 정의서와 맞추기
```
