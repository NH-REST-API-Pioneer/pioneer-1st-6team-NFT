# R12 · 「야간 모의 환경 미지원」이라고 적힌 국내 차트·호가가 모의 서버에서 야간 데이터를 돌려줍니다

- 섹터: 2 · 종류: 명세 설명과 실제 동작 불일치 · 검증: 실제 호출 · AI 영향: 상 (명세를 믿으면 모의에서 야간 데이터를 쓸 수 없다고 판단)
- 상태: 올릴 준비 됨

```text
[제보] 국내_차트(일·분)·국내_호가 설명에 「야간 모의 환경 미지원」이라고 돼 있는데, 모의 서버에서 야간 데이터가 정상으로 옵니다

팀: team-06
환경: 모의 (apidemo.futures.co.kr), 2026-11-22 22:53 최초, 22:55 재현 (일요일, 11/20 주간·11/20~21 야간 데이터)
대상: 국내_차트(분) POST /trade/v1/domestic/chart-minute  https://apidev.futures.co.kr/#/api?g=118&a=236&v=1
      국내_차트(일) POST /trade/v1/domestic/chart-daily   https://apidev.futures.co.kr/#/api?g=118&a=237&v=1
      국내_호가     POST /trade/v1/domestic/price-bid     https://apidev.futures.co.kr/#/api?g=118&a=244&v=1

재현 절차:
  1. 접근토큰 발급 (모의)
  2. 국내_차트(분) {"nght_tp":"1","sym":"A756C000","req_qty":"3","dcnt":"1"} 과 nght_tp 만 "2" 로 바꾼 요청
  3. 국내_차트(일) 같은 방식으로 nght_tp 1 / 2
  4. 국내_호가 {"exch_cd":"KSP","sym":"A756C000"} 과 exch_cd 만 "NDV" 로 바꾼 요청

기대 결과:
  세 API 공통 설명 「(* 야간 모의 환경 미지원)」에 따라, 모의 서버에서 야간(nght_tp 2, exch_cd NDV)은
  오류(예: EGW053 「해당 API는 모의투자에서 호출할 수 없습니다.」)로 거절되거나, 모의에서 허용되는 범위가 명세에 구분 표기되어야 함

실제 결과:
  차트(분) nght_tp 1 → 20261120 154500 1335.60 (주간 마지막 봉)
           nght_tp 2 → 20261121 060000 1345.30, 054900, 054800 … (야간 마감까지의 봉)
  차트(일) nght_tp 1 → 20261120 종가 1335.60 거래량 705291
           nght_tp 2 → 20261120 종가 1345.30 거래량 31841 (야간 세션 일봉)
  호가     KSP → 호가시간 154500, 현재가 1335.60 / NDV → 호가시간 060000, 현재가 1345.30
  → 세 API 모두 모의에서 야간 데이터를 정상(HTTP 200)으로 돌려줌
  → 반대로 「(* 모의 환경 미지원)」이 적힌 국내_현재가(야간)·국내_옵션전체시세(야간)은 실제로 HTTP 400 EGW053 「해당 API는 모의투자 에서 호출 할수 없습니다.」로 거절됨 (대조)

로그·캡처: (저장소) error_reports/2-국내시세/logs/market_20261122_225342.json (최초 호출·야간 전용 API EGW053 대조),
          logs/market_values_20261122_225432.json, logs/market_repro_20261122_225559.json (재현 원문)
          스크립트 error_reports/2-국내시세/check_market.py, check_market_values.py
영향:
  - 명세를 믿는 사용자·AI 에이전트는 모의 환경에서 야간 차트·호가를 쓸 수 없다고 보고 야간 전략 시험을 포기하거나 다른 경로를 찾음
  - 반대로 「미지원」인 줄 알면서 받은 데이터가 맞는 데이터인지, 추후 차단될지 판단할 수 없음
개선 제안:
  1) 모의에서 야간 과거·마감 시세 조회를 허용하는 설계라면, 세 API 설명에서 「(* 야간 모의 환경 미지원)」을 빼거나 모의에서 되는 범위(차트·호가 조회)와 안 되는 범위(현재가(야간)·옵션전체시세(야간)·야간 주문 EGW053)를 구분해 적기
  2) 의도치 않은 노출이라면 야간 전용 API와 같이 모의 야간 요청을 EGW053 으로 차단해 동작과 문서를 맞추기
  3) 같은 「(* 야간 모의 환경 미지원)」 문구가 붙은 다른 공용 API(국내_종목예상체결가·품목별세부정보·주문가능수량·주문내역)도 실제 모의 지원 범위에 맞춰 문구 일괄 정비
```
