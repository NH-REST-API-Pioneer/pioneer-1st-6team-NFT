# R14 · 국내_투자자직전매매동향: 오래된 날짜로 부르면 오류 응답의 errorCode·errorMessage 값이 뒤바뀌어 옵니다

- 섹터: 2 · 종류: 서버 오류 응답 결함 · 검증: 실제 호출 (2회 재현) · AI 영향: 중 (errorCode 로 분기하는 처리가 깨짐)
- 상태: 올릴 준비 됨

```text
[제보] 국내_투자자직전매매동향에 2020년 날짜를 넣으면 errorCode 에 긴 메시지가, errorMessage 에 "ERC008" 이 들어간 오류가 옵니다

팀: team-06
환경: 모의 (apidemo.futures.co.kr), 2026-11-22 22:55 (3회 동일)
대상: 국내_투자자직전매매동향 POST /trade/v1/domestic/trend-investor  https://apidev.futures.co.kr/#/api?g=118&a=240&v=1

재현 절차:
  1. 접근토큰 발급
  2. {"opt_prd":"011","ref_dt":"20200101","inq_tp":"1"} 로 호출 (20200102 도 같음)
  3. 비교: ref_dt "20250102" → 정상 데이터

기대 결과:
  데이터가 없는 날짜면 빈 결과, 오류라면 {"errorCode":"ERC008","errorMessage":"오류가 발생하였습니다…"} 형식

실제 결과:
  HTTP 400
  {"errorMessage":"ERC008",
   "errorCode":"오류가 발생 하였습니다.\n ErrorCode: ETR045, Message: 응답 데이터 처리중 에러가 발생했습니다. 변환할 데이터 길이가 부족합니다. [key=occurs1_tm](필요한 데이터 길이=6, 남은 데이터 길이=0)",
   "errorStatus":400, "errorPath":"/trade/v1/domestic/trend-investor", …}
  → errorCode 와 errorMessage 의 값이 서로 바뀌어 있음
  → 메시지 안의 ETR045 는 오류 코드 페이지·정의서에 없음
  → 「응답 데이터 처리중 에러」는 서버 쪽 변환 실패로 보임 (요청은 형식이 맞음: 2025-01-02 는 정상, 2020-01-01 은 실패)
  → 참고: 메시지의 occurs1_tm 은 이 API 명세·실제 응답에 없는 필드 (응답은 최상위 tm)

로그·캡처: (저장소) error_reports/2-국내시세/logs/market_repro_20261122_225559.json (trend-investor ref_dt=20200101)
영향:
  - errorCode 를 코드표와 대조하는 오류 처리는 이 응답을 알 수 없는 코드로 처리하고, 메시지를 보여 주는 화면에는 "ERC008" 만 보임
  - 오래된 날짜를 넣은 사용자 실수인지 서버 오류인지 구분할 수 없음
개선 제안:
  1) errorCode·errorMessage 필드를 바로잡기
  2) 데이터가 없는 날짜는 빈 결과나 「조회 가능 기간이 아닙니다」 같은 오류로 응답하고, 조회 가능 기간을 명세에 적기
  3) ETR045 를 정의서에 추가하거나 사용자에게 보이지 않게 처리
```
