# R03 · 배열 응답(Occurs1)의 응답 샘플이 단일 객체로 그려져 있습니다 (실제는 객체 배열)

- 섹터: 0 · 종류: 명세 오류 (샘플) · 검증: 실제 호출 (국내 7 + 해외 9) · AI 영향: 중
- 상태: 올릴 준비 됨. 약점: 같은 페이지 응답 바디 표의 설명은 `Array[{Object}]` 로 맞음 → 「표와 샘플이 서로 다르다」로 씀

```text
[제보] 배열 응답(Occurs1)이 있는 API 의 「응답 샘플」이 단일 객체로 그려져 있습니다. 실제 응답은 객체 배열이고, 0건이면 키가 빠집니다

팀: team-06
환경: 모의 (apidemo.futures.co.kr), 최초 2026-10-27 16:41, 재현 2026-11-20 23:14
대상: 응답에 Occurs1 이 있는 조회 API 24개의 「응답 샘플」

  1. 접근토큰 발급 (국내 모의 키, 해외 모의 키)
  2. 국내_차트(분)을 {"nght_tp":"1","sym":"A756C000","req_qty":"3","dcnt":"1"} 로 호출
  3. 같은 방식으로 Occurs1 이 있는 조회 API 를 호출해 Occurs1 의 타입 확인

기대 결과 (웹 가이드 응답 샘플):
  {"nxt_key":"","sym":"","nrec":"","Occurs1":{"occurs1_ref_dt":"", …}}   ← Occurs1 이 객체 하나

실제 결과:
  {"nxt_key":"20261120153300","nrec":"3","Occurs1":[{"occurs1_ref_dt":"20261120",…},{…},{…}]}   ← 객체 배열
  데이터가 있는 16개 모두 배열:
    국내 호가(10건)·차트(일)(3)·차트(분)(3)·선물전체시세(222)·옵션전체시세(261)·종목예상체결가(100)·품목별세부정보(28)
    해외 현재가(1)·차트(일)(3)·차트(분)(3)·옵션전체시세(323)·품목별세부정보(100)·장운영정보(100)·만기일조회(1)·누적손익현황(2)
  조회 결과가 0건인 계좌 API(국내 잔고·주문오류·주문내역·미결제약정, 해외 주문오류·주문내역·잔고·보유포지션만기)는
  Occurs1 키 자체가 없이 {"nxt_key":"","nrec":"0000"} 으로 옴 (명세에 이 동작 설명 없음)
  → 응답 바디 표의 설명(Occurs1: Array[{Object}])은 맞고, 응답 샘플만 단일 객체로 다름
  → 「Excel 다운로드」(11/20)의 Response JSON 은 Occurs1 을 "" 로 두고 occurs1_* 를 최상위에 나열해 또 다름

          국내_차트(분) 응답 샘플 캡처

  - 0건일 때 resp["Occurs1"] 로 꺼내면 KeyError
  - 샘플을 응답 구조로 읽는 도구(코드 생성기, AI 에이전트)가 배열을 단일 객체로 처리함

개선 제안:
  1) 응답 샘플을 "Occurs1": [ { … } ] 배열로 생성 (배열 길이 표기를 반영)
  2) 0건이면 Occurs1 이 빠진다는 점을 명세에 적거나, 빈 배열 [] 로 응답
  3) 엑셀 Response JSON 도 같은 중첩 구조로 수정
```
