# R07 · 명세 표기 오류 모음 (설명 잘림·이름 중복·오타)

- 섹터: 0 · 종류: 문서 오류·오타 · 검증: 문서 대조 · AI 영향: 하
- 상태: 올릴 준비 됨 (우선순위 낮음, 마지막에)

```text
[제보] 명세 표기 오류 모음: nxt_key 설명 잘림(11개 API), 한글명 중복·오표기, 오타·설명 오류

팀: team-06
환경: 개발자센터 웹 가이드·「Excel 다운로드」·오류 코드 페이지·「오류 코드 정의서」, 2026-11-20·11-22 확인
대상: 아래 API 의 요청·응답 바디 설명·한글명

실제 결과 (웹·엑셀 같음):
  1. 응답 nxt_key 설명이 「기본」 한 단어로 끊김 (요청 바디 쪽은 「기본:공백\n...」, 차트 API 응답은 「기본:99999999」)
     국내_잔고내역, 국내_주문오류내역, 국내_주문내역, 해외_품목별세부정보, 해외_장운영정보, 해외_주문오류내역,
     해외_주문내역, 해외_잔고내역, 해외_만기일조회, 해외_보유포지션만기조회, 해외_누적손익현황 (총 11개)
  2. 한글명 중복·오표기
     - 해외_주문내역: occurs1_qt_tp(1 신규·2 정정·3 취소)와 occurs1_ord_div(0 DAY·1 GTC·6 GTD)가 둘 다 「주문구분」
       → 뒤의 것은 「주문유효구분」 등으로 구분 필요
     - 해외_옵션전체시세: occurs1_c_exec_cd·occurs1_p_exec_cd 한글명이 「콜종목코드」·「풋종목코드」로 기재돼 있으나 실제 응답값은 거래소코드("CME")이며, 실제 종목코드는 바로 다음 필드인 occurs1_c_sym("O_ESZ26-C12000.0")·occurs1_p_sym("O_ESZ26-P12000.0")(한글명 둘 다 「종목코드」로 중복)
  3. 오타 및 설명 오류
     - 국내_옵션전체시세(야간) prd 설명: `09:코스피200위클릭(목)` / `AF:코스피200위클릭(목)`
       → 두 줄 모두 「위클리」 오타이며, 서로 다른 코드 `09`·`AF`가 둘 다 `(목)`으로 중복 표기됨 (아래 `AJ:코스닥150위클리(목)` / `AK:코스닥150위클리(월)`처럼 요일 구분 확인 필요)
     - 해외_차트(일) 설명: 「헤외 차트 기간별 데이터 (일) PIBO7503」 → 해외
     - 국내_투자자직전매매동향 ins_sel_rt 한글명: 「모험매도대비율」 → 보험매도대비율
     - 해외_품목별세부정보·해외_만기일조회 occurs1_exch_cd 한글명: 「거래소V코드」 → 거래소코드
     - 해외_품목별세부정보 요청 prd_nm 설명: 「prd_cd(검색구분코드)에 따라 입력 / 공백:공백 / 1:품목명 / 2:공백」
       → prd_cd=2 는 상품코드 검색이므로 「2:상품코드(품목코드)」로 수정 필요
     - 실시간 8개 API 페이지 「도메인 정보」 안 「실시간 처리 안내」: 「실시간 처리 샘플 (Pythone)」 → Python
     - 오류 코드 페이지(`/#/api/info/error-code`)·「오류 코드 정의서」 ETR001: 「입렵 맵에 키 '%s' 가 존재하지 않습니다.」 → 입력

영향: 명세를 읽는 사람·도구가 다음 페이지 키 기본값, 검색 조건 입력 규칙, 품목코드 요일 구분을 알 수 없고, 같은 이름이나 잘못 붙은 한글명의 필드를 혼동함
개선 제안: 위 설명·한글명·오타 수정. 1 은 「기본: 공백 (응답 데이터가 요청 건수를 초과하면 다음 조회 키)」 처럼 요청 쪽 설명과 맞추기
```
