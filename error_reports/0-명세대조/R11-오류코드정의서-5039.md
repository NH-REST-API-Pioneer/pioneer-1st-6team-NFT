# R11 · 오류 코드 정의서: `5039` 중복 등재 및 예시 시트와의 불일치

- 섹터: 0 (문서) · 종류: 오류코드 문서 오류 · 검증: 정의서 전수 대조 + 다른 팀 실측·운영진 답변 · AI 영향: 중 (코드→뜻 표를 그대로 쓰면 충돌·오해 발생)
- 상태: 올릴 준비 됨

```text
[제보] 오류 코드 정의서 「주문오류 ERROR」 표에 5039 가 서로 다른 메시지로 두 번 중복 등재돼 있고, 「오류코드 목록」 예시 시트와 불일치합니다

팀: team-06
환경: 개발자센터 「오류 코드」 페이지 > 「오류 코드 정의서 다운로드」 (오류코드_정의서.xlsx, 2026-11-20 받음)
대상: 정의서 「주문오류 ERROR」 시트(103건), 「오류코드 목록」 시트 [예시], 「시스템 ERROR」 시트(19건)

실제 내용:
  1. 「주문오류 ERROR」 시트 내 5039 중복 등재 (103건 중 유일한 중복 코드)
     No 1   5039 | 거래소 (야간)개장전입니다.
     No 38  5039 | 처리불가 [(시장가)호가유형별 호가입력제한오류]
  2. 「오류코드 목록」 시트 [예시]의 5039 설명과 구조 불일치
     「- 5039 처리불가 [해당주문은 가격 보류 기준(100) 초과되었습니다(800)]」
     「- 5039 처리불가 [주문증거금총액 부족]」
     「- 5039 처리불가 [호가단위(0.05). 오류]」
     「5039과 같은 경우 주문오류 조회 시 상세 내역 확인 가능」
  3. (함께 발견된 같은 파일 내 불일치)
     - 「오류코드 목록」 [예시]에 적힌 `EGW052`(토큰 재발급이 필요합니다)가 「시스템 ERROR」 시트에 없음
     - 「오류코드 목록」 [예시]에 적힌 `7027`(장 종료후 입니다)이 「주문오류 ERROR」 시트에 없음
     - 「오류코드 목록」 [예시] 3번이 숫자 주문오류 코드를 「숫자로만 구성된 시스템 ERROR」로 표기 (실제 시트명은 「주문오류 ERROR」)

기대 결과:
  코드 표는 코드 하나당 한 줄로 정리돼 있어야 하며, 5039 가 여러 사유를 담는 포괄 코드라면 표에도 포괄 설명으로 일관되게 기재되고, 예시 시트에 등장하는 코드는 세부 시트에서도 조회 가능해야 함.

문제:
  - 「주문오류 ERROR」 표에 5039 가 서로 다른 단일 사유 두 줄(No 1, No 38)로 중복돼 있어 코드→설명 매핑 시 충돌 발생
  - [예시] 시트와 실제 응답(team-08 10/30 제보: 시장가 FAK → 5039 「처리불가 [시장가는 FOK, FAK 주문불가입니다 ]」, 운영진 확인)을 보면 5039 는 여러 거부 사유를 담는 포괄 코드인데, 표에는 특정 메시지 두 건만 각각 적혀 있음
  - [예시]의 「주문증거금총액 부족」·「호가단위 오류」는 같은 표에 별도 코드 `52`·`50802` 로도 존재해, 어떤 조건에서 5039 vs 개별 코드로 내려오는지 문서만으로 구분 불가

영향:
  - 정의서를 코드→뜻 매핑 표로 파싱하는 프로그램·AI 에이전트가 5039 를 1번(「개장전」) 또는 38번(「시장가 호가입력제한」) 한 가지 뜻으로만 고정 해석해 실제 거부 사유와 다른 대응을 함
개선 제안:
  1) 「주문오류 ERROR」의 5039 중복 두 줄을 한 줄로 통합하고, 「처리불가 — 상세 사유는 메시지 또는 주문오류내역 조회로 확인」처럼 포괄 코드 성격 명시
  2) 「오류코드 목록」 [예시]에 언급된 `EGW052`·`7027`을 해당 시트에 추가하고, [예시] 3번의 「시스템 ERROR」 표기를 「주문오류 ERROR」로 수정
  3) (가능하다면) 52·50802 같은 별도 코드와 5039 포괄 코드의 발생 구분 기준을 간단히 안내
```
