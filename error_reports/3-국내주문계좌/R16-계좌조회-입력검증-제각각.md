# R16 · 국내 계좌 조회 API 의 입력 검증이 API·필드마다 다르고, 쓰이는 오류 코드(5011·5040)가 정의서에 없습니다

- 섹터: 3 · 종류: 입력 검증 불일치 + 오류코드 문서 누락 · 검증: 실제 호출 · AI 영향: 중
- 상태: 올릴 준비 됨

```text

재현 절차:
  1. 접근토큰 발급
  2. 아래 필드에 명세에 없는 값을 넣어 호출

기대 결과:
  명세에 값이 정해진 필드는 같은 방식(같은 오류 코드)으로 거절되고, 그 코드는 오류 코드 정의서에 있음

  | API · 필드 (명세 값)                         | 넣은 값   | 결과                                               |
  | 주문내역 trd_div (0 전체, 1 매수, 2 매도)      | 9         | 400 5011 「[매수매도구분코드] 코드 오류입니다.」       |
  | 주문오류내역 trd_div_cd (0, 1, 2)             | 9         | 400 5011 「[매수매도 구분코드] 코드 오류입니다.」      |
  | 주문내역 ord_div_cd (0 전체, 1 거부, 2 오류)   | 9         | **200 정상** (거절 안 함)                            |
  | 주문가능수량 trd_div (1 매수, 2 매도)          | 9         | **200 정상**                                       |
  | 주문가능수량 ord_sts (1~4 주간/야간·일반/법인) | 9         | **200 정상** (결과도 1 과 같음)                      |

  → 같은 「매수매도 구분」 필드인데 주문내역·주문오류내역은 거절, 주문가능수량은 받아들임
  → 같은 「날짜 8자리」 필드인데 예수금은 형식 오류(ETR018), 미결제약정은 「자료 없음」(5040)

  1) 같은 의미의 필드(매수매도 구분, 날짜)는 모든 API 에서 같은 검증·같은 오류 코드로
```
