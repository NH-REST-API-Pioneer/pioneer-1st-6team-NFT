# 오류 제보 (team-06)

NH선물 REST API 명세와 실제 동작을 API 별로 맞춰 보며 찾은 오류를 섹터별로 모아 둔 폴더입니다. Discord `#오류-문의` 에는 채널이 도배되지 않게 **하루 1\~2건씩** 아래 순서로 올리고, 본문에 해당 파일 링크를 답니다.

점검 방식은 [점검-방식.md](점검-방식.md) 에 있습니다. 요약하면 「명세대로 보내면 명세대로 오는가」를 API 마다 모의 서버로 확인하고, 다르면 근거(로그·대조 결과)와 함께 제보합니다.
